# 末班车：十三号站 V2.5

一款单人规则推理构筑游戏。玩家担任终雾线的深夜检票员，在三夜十八位随机乘客中调查异常，通过管理抽牌、弃牌与策略牌，同时依据每晚规则和逐人变化的闸机令决定放行或拒载。

在线试玩：[GitHub Pages](https://weiwei-cup.github.io/last-train-thirteen-station/)

## 游戏内容

- 三个夜晚、二十四位候选乘客，每局随机编组十八位，并优先避开上一局阵容
- 八类逐人闸机令围绕票号、票种、路线、年龄和行李生成临时条件，同一人物每局可能得到不同结论
- 例行查验、重点复核、红色终审三级门槛，依次要求 1、2、3 条复核记录
- 二十四张独立生成的旧铁路档案风格人物肖像
- 六种随机线路异况会改变调查费用、专注或津贴
- 六种随机夜班密令提供不同的额外挑战与奖励
- 三种交叉核验组合可把两条线索合成为新的综合结论
- 每夜一次的乘警协查可免费补齐一项关键调查
- 真实的抽牌堆与弃牌堆循环：牌库耗尽后自动洗回，手牌资源会跨乘客流转
- 每位乘客抽取四张牌，并可支付专注弃掉当前手牌、重整一次
- 五种策略牌可恢复专注、免费调查、保留手牌或提高处置收益
- 每夜最后两位进入红色终审，综合结论与人物连锁也可计入复核门槛，正确处置另有奖励
- 两次夜间强化会带来常驻能力，并向调查牌组加入对应调查牌或策略牌
- 游戏内牌组总览可随时查看牌型数量、抽牌堆、弃牌堆与策略使用次数
- 每夜一组人物连锁事件：首位乘客的处置会改变末位乘客获得的关系线索
- 常规值班、熄灯巡查与雾线直达三种难度契约
- 车票、银镜、问询、心跳和行李五类调查牌，以及五类特殊策略牌
- 信誉、四级车厢污染与有限专注形成的风险取舍
- 连续正确判断带来的递增津贴与记录倍率
- 每局重新洗牌的两次值班牌强化选择
- 保存在当前浏览器中的乘客档案与最佳连判
- 键盘、鼠标与触屏操作
- 浏览器本地保存最高记录与完成局数

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```
