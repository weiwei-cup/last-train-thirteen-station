# 末班车：十三号站

一款单人规则推理卡牌游戏。玩家担任终雾线的深夜检票员，在三夜十二位乘客中调查异常，并依据每晚变化的临时规则决定放行或拒载。

在线试玩：[GitHub Pages](https://weiwei-cup.github.io/last-train-thirteen-station/)

## 游戏内容

- 三个夜晚、二十四位候选乘客，每局随机编组十二位，并优先避开上一局阵容
- 二十四张独立生成的旧铁路档案风格人物肖像
- 六种随机线路异况会改变调查费用、专注或津贴
- 六种随机夜班密令提供不同的额外挑战与奖励
- 三种交叉核验组合可把两条线索合成为新的综合结论
- 每夜一次的乘警协查可免费补齐一项关键调查
- 常规值班、熄灯巡查与雾线直达三种难度契约
- 车票、银镜、问询、心跳和行李五类调查行动牌
- 信誉、车厢污染与有限专注形成的风险取舍
- 连续正确判断带来的递增津贴与记录倍率
- 每局重新洗牌的两次值班牌强化选择
- 保存在当前浏览器中的乘客档案与最佳连判
- 键盘、鼠标与触屏操作
- 浏览器本地保存最高记录与完成局数

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```
